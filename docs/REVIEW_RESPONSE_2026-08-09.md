## 第五轮评估热修复（1.5.8）

线上用户反馈“页面一直刷新和抖动”。复现确认：上一版 SW 注册每次加载带新时间戳，浏览器把新 URL 当作新 worker 重新接管，`controllerchange` 又触发自动刷新，形成无限刷新循环。

### 修复

- Service Worker 注册改为固定 `./sw.js` 地址并 `updateViaCache: none`。
- 只有 SW 内容真正变化时，浏览器才会安装新 worker 并触发一次自动刷新；正常访问不再循环。

### 验证

- Playwright 持久化上下文复测：连续 3 次 reload 均稳定，无额外导航。
- 建档 → 测评 → 主线 → 决策 → 1v1 完整流程继续通过。
